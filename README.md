# Хан Кене — интерактивті оқу платформасы

**Тақырып:** «Қазіргі қазақ прозасындағы тарихи тұлғаны көркем реконструкциялау»
**Тарихи тұлға:** Кенесары хан (1802–1847)

І. Есенберлиннің «Қаһар» романындағы **тарихи шындық** пен Ғ. Бекахметовтің
«Барсакелмес: Көшпенділердің оралуы» шығармасындағы **көркем реконструкцияны**
салыстыруға арналған React платформасы.

## Құрылымы

Басты бетте — Қазақстан картасы, үстінде 5 белгі (пин). Әр белгі — жеке тапсырма.
Орындалған тапсырма ✔ таңбасымен белгіленеді (нәтиже `localStorage`-та сақталады).

| № | Тапсырма | Түрі |
|---|----------|------|
| 1 | Теория және ресурстар | «Қаһар» / «Барсакелмес» блоктары + анықтамалық |
| 2 | Тарихи бейнені тану | Экспресс-тест, 10 сұрақ |
| 3 | Сөзжұмбақ пен сәйкестендіру | 4 үзінді + 6 терминді анықтамасымен сәйкестендіру |
| 4 | Тарих пен көркем сөз | А: дерек пе, реконструкция ма (10 сөйлем) · Б: сызықпен жалғау (5 жұп) |
| 5 | Жаңа Кенесары портреті | 12 дерек, тек «Барсакелмес» деректерін таңдау (drag & drop) |

## Дыбыс

Барлық дыбыс **Web Audio API** арқылы браузерде синтезделеді — сыртқы файл жоқ,
интернетсіз де жұмыс істейді:

- дұрыс жауап — мажорлық арпеджио;
- қате жауап — төмен түсетін ескерту сигналы;
- тапсырма аяқталғанда — фанфар;
- фондық әуен — пентатоникалық баяу арпеджио (жоғарғы оң жақтағы түймемен қосылады/өшіріледі).

## Іске қосу

```bash
npm install
npm run dev        # http://localhost:5173
```

## Деплой

```bash
npm run build      # нәтижесі dist/ ішінде
npm run preview    # жиналған нұсқаны тексеру
```

`dist/` — статикалық файлдар. Vercel / Netlify / GitHub Pages-ке сол күйінде
жүктей беруге болады (`vite.config.js` ішінде `base: './'` тұр, сондықтан кез келген
ішкі каталогтан ашылады).
